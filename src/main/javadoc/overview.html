Public API for addons to Cozy Voice Chat, a proximity voice chat mod for Minecraft Forge 1.20.1. API version 1, mod 1.1.0 or newer, MIT licensed.

Only net.elgerelg.cozyvoicechat.api and its subpackages are public; everything else in the mod is internal. The full guide with more examples is API.md.

Quick start

1. Gradle (JitPack)

{@code
repositories {
    maven { url 'https://jitpack.io' }
}
dependencies {
    // API only: no Minecraft method references, so no fg.deobf is needed
    compileOnly 'com.github.ElgerElg.CozyVoiceChat:cozyvoicechat-api:'
    // optional: the real mod in dev runs
    runtimeOnly fg.deobf('com.github.ElgerElg.CozyVoiceChat:cozyvoicechat:')
    minecraftLibrary 'io.github.jaredmdobson:concentus:1.0.2'
}
}

<tag> is a release tag of the repository, e.g. v1.1.0. Do not ship the API jar inside your mod; players install Cozy Voice Chat itself.

2. mods.toml

[[dependencies.yourmodid]]
modId="cozyvoicechat"
mandatory=true            # or false for an optional integration
versionRange="[1.1.0,)"
ordering="AFTER"
side="BOTH"

3. Get the API

{@code
if (CozyVoiceApi.isAvailable()) {
    CozyVoiceApi api = CozyVoiceApi.get();     // any time after mod construction
    ServerVoiceApi server = api.server();      // logical server
    ClientVoiceApi client = api.client();      // physical client only
}
}

See {@link net.elgerelg.cozyvoicechat.api.CozyVoiceApi}, {@link net.elgerelg.cozyvoicechat.api.server.ServerVoiceApi} and {@link net.elgerelg.cozyvoicechat.api.client.ClientVoiceApi}.

4. Listen to events

Events are normal Forge events on MinecraftForge.EVENT_BUS:

{@code
@SubscribeEvent
public static void onRoute(VoiceRouteEvent e) {
    ServerPlayer sender = e.getSender();
    if (!Radio.isTransmitting(sender)) return;
    for (ServerPlayer p : sender.server.getPlayerList().getPlayers()) {
        if (p != sender && Radio.isListening(p)) {
            e.getTargets().add(new VoiceTarget(p.getUUID(), VoiceCategory.RADIO, 1f));
        }
    }
    e.setRadioEffect(true);
}
}

5. Mutes, groups and audio

{@code
ServerVoiceApi voice = CozyVoiceApi.get().server();
voice.mute(player.getUUID(), 300);                       // 5 minutes, fires VoiceMuteChangedEvent

VoiceGroup team = voice.createGroup("Red team", false);  // members hear each other anywhere
team.addMember(player.getUUID());

LocationalAudioChannel speaker = voice.createLocationalChannel(null, level, Vec3.atCenterOf(pos));
AudioPlayer music = voice.createAudioPlayer(speaker, nextFrameOrNull);  // 960-sample frames, null = end
music.onStopped(speaker::close);
music.start();
}

6. Register your addon (optional)

{@code
@CozyVoiceAddon
public final class MyVoiceAddon implements CozyVoicePlugin {
    @Override public String getId() { return "myaddon"; }

    @Override public void onRegister(CozyVoiceApi api) {
        MinecraftForge.EVENT_BUS.register(MyVoiceEvents.class);
    }
}
}

Cozy Voice Chat finds annotated classes in Forge's scan data during common setup, creates them and calls {@link net.elgerelg.cozyvoicechat.api.addon.CozyVoicePlugin#onRegister(net.elgerelg.cozyvoicechat.api.CozyVoiceApi)}. They are listed in the log, by /cozyvoice addons and by {@link net.elgerelg.cozyvoicechat.api.CozyVoiceApi#getAddons()}. See {@link net.elgerelg.cozyvoicechat.api.addon.CozyVoiceAddon}. A complete example: CozyVoiceChat-SampleAddon.
